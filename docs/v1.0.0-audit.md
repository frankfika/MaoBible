# v1.0.0 Audit Report

**Date**: 2026-08-03
**Scope**: full MaoBible v1.0.0 readiness review
**Method**: 6 parallel sub-agent audits (UX/UI, Functional, PWA/Performance, i18n/Content, Storage/Data, Release-readiness) + manual code walk-through
**Result**: 147 raw findings → ~30 distinct issues, **all P0 + most P1 fixed in this commit**. P2/P3 + owner-action items left for follow-up.

---

## 1. 用户故事 — 卡住场景 (P0 — all fixed)

- 角色读者进 Reader, 看到旧 80% 滚动位置 (audit 发现 `getReadingProgress` 后 `scrollTo` 覆盖用户当前位置). 修: 加 `userTouched` guard, 仅在用户没动时 restore.
- 角色读者切 "中→英" 内容语言, 段落 button 突变 `<p>`, 焦点/状态丢失. 修: `ParagraphView` 总是 button (或总是 p), onTap undefined 走 p 分支.
- 角色读者点 ☆ 收藏, 跳到文章顶部. 修: bookmark 存当前活动段 id (fallback 到第一个 body 段).
- 角色读者切 "双语", 但文章没英文, 工具栏仍 active 单栏显示. 修: 检测 secondary 缺, 自动 fallback + 顶部提示.
- 角色用户提交"回应", AI 失败, 显示 fallback 文案当作成功. 修: `callAI` 返 `AIResult { text, isFallback }`, UI 显式标注 "AI 不可用".
- 角色用户在 Ask 切 mode, 旧 stage 文案残留. 修: `inflightRef` 取消 in-flight, mode 切换清 stage/loading.
- 角色读者 iPadOS 13+ 桌面模式, 看到 Android 安装提示. 修: `detectIOSLike()` 加 Mac + touchPoints 检测.
- 角色读者 320px 屏, Reader 工具栏 7 按钮溢出. 修: `overflow-x-auto`.
- 角色读者进 Shelf 选了"认识论", 切 Me 回来变 "全部". 修: 主题 filter 持久化 localStorage.
- 角色 Me 页看不到对话, 隐私页却承诺"应用内删除对话". 修: Me 加对话历史 section.
- 角色用户跨日 23:59 读 5 分钟, 次日 00:01 退出, 统计到昨天. 修: daily bucket 改本地日期.
- 角色开发者 deploy /privacy, EdgeOne token URL 401. 这是 owner 域名绑定问题 — 部署 OK, 需 Frank 在 console 绑 maobible.app.
